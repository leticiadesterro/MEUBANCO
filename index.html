Importe um JSON gerado no ChatGPT. Uma importação adiciona questões novas e preserva as anteriores. Registros com o mesmo identificador não são duplicados.

Backup e gerenciamento

Os dados ficam armazenados neste navegador/dispositivo. Exporte backups frequentemente: limpar os dados do navegador pode apagar o banco.

Como preparar arquivos para importar

Envie aqui no ChatGPT a prova em PDF, seu gabarito e o gabarito oficial e peça um arquivo JSON para o Meu Banco de Questões. Cada questão deve conter texto integral, alternativas, temas e sua situação.

Os campos essenciais são prova, ano, numero, enunciado, alternativas, gabarito, minha_resposta, situacao, grande_area, tema_geral e tema_especifico. Em provas não realizadas, use situacao: "nao_fiz".
